# ios-vocie

iOS voice and IM prototype for Xiao Xing.

Current capabilities:

- Wake word entry for `小星小星`, with text compatibility for `小心小心`.
- IM chat and full-screen voice call interaction.
- Reminder intent parsing for alarms, medication, and general reminders.
- Smart watch data query intent parsing for heart rate, blood oxygen, sleep, location, battery, events, and medication records.
- Reserved iFlytek AIKit wake word SDK integration.
